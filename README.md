# Matter Switchyard — מסילת החומר

A tactile 3D toy-rail dispatch puzzle: keep a tiny chemistry freight network flowing by inspecting sample wagons and throwing hierarchical switches before queues collide.

Status: design handoff; builder implementation is starting. Proposed screenshot images are visual targets, not proof of implemented gameplay.

See [BUILD_HANDOFF.md](BUILD_HANDOFF.md) and [COMMON.md](COMMON.md) for curriculum, asset workflow and acceptance criteria.

The intended stack is TypeScript with a real 3D engine, Hebrew RTL interface and a browser-playable single-player slice. Local development port: 5191.
